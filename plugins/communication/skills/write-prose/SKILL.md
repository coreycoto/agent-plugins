---
name: write-prose
description: Draft or substantially rewrite explanatory prose for documents, reports, briefs and user-facing text using the supplied audience, purpose and evidence.
---

Identify the audience, purpose and desired action from the request. Infer routine choices when the context supports them. Ask about a missing choice only if it materially changes the document; otherwise state the relevant assumption and proceed.

Build the draft around one clear main point. Put the reader's immediate need first and supply the evidence and explanation required to assess it. Give each paragraph one developing idea. Prefer concrete nouns and active verbs; explain jargon only when the audience needs it. Scale headings, tables and lists to the length and use of the document.

Separate supplied facts, reasonable inference and proposed language. Preserve links or citations for claims that require them. Do not invent metrics, quotes, customer evidence, guarantees or endorsements to make the prose persuasive. Mark a material evidence gap in the working draft or ask for the missing fact.

Adapt tone to the supplied style and medium. An accessible technical explanation can retain necessary detail. A short answer does not need a miniature report. For persuasive campaign copy, use an available marketing workflow when needed; do not infer a brand, target audience or conversion objective absent context.

Read the complete draft for logic and repetition before delivering it. Supply an editable artifact if requested. Drafting does not authorize sending or publishing it.
