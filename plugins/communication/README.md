# Communication

An independently selectable package for agent updates and answers, explanatory
writing, and editing. Consumer style, audience and facts stay in the task or its
repository. Skills do not grant messaging or publication authority.

Use `agent-communication` during task collaboration, `write-prose` for substantial
drafts, and `edit-prose` for supplied text. Product discovery belongs to Product
Management; delivery tracking to Project Management; code changes to Product
Development. Campaign strategy and brand positioning need their own context.
